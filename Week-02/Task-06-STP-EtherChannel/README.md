
Week 2 - Task 6: STP and EtherChannel

Description

In this lab, I configured Rapid PVST+, Root Bridge Election, PortFast, BPDU Guard, and LACP EtherChannel using Cisco Packet Tracer

Practical Tasks

Configured Rapid PVST+

Observed STP blocking to prevent Layer 2 loops

Identified the Root Bridge

Changed bridge priority to elect a new Root Bridge

Configured PortFast and BPDU Guard on access ports

Configured LACP EtherChannel between two switches

Verified configurations using show commands

Tools Used

Cisco Packet Tracer

Cisco 2960 Switches

PCs

Verification

show spanning-tree vlan 1

show spanning-tree interface fa0/3 detail

show etherchannel summary

show running-config

Result

Successfully configured and verified STP, PortFast, BPDU Guard, and LACP EtherChannel
