Task 01 — CCNA Lab Setup and How Networks Work

Objective

To understand basic networking concepts and build a small network using Cisco Packet Tracer

Tools Used

Cisco Packet Tracer

Lab Topology

2 Routers

2 Switches

4 PCs

Tasks Completed

Created a basic network topology

Connected routers, switches, and PCs

Configured IP addresses on end devices

Tested connectivity using the ping command

Verified communication between PCs

Verification

Used the ping command to test connectivity between the end devices

Learning Outcomes

Understood the basic roles of routers and switches

Learned how devices communicate over a network

Practiced basic IP addressing.

Verified end-to-end connectivity.
