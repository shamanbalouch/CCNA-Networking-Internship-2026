Task 03 — Cisco IOS CLI, Interfaces, and Recovery

Objective

To learn Cisco IOS command-line operations, device configuration, interface management, SSH access, configuration backup, and password recovery.

Tasks Completed

Configured device hostnames and login banners

Configured enable secret and console/VTY passwords

Configured SSH for secure remote access

Practiced User EXEC, Privileged EXEC, and Global Configuration modes

Executed and analyzed important show commands

Saved configurations using copy running-config startup-config

Reloaded devices to verify configuration persistence

Practiced router password recovery using the configuration register

show ip interface brief
show version
copy running-config startup-config
reload
