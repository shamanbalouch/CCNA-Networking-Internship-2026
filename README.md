About This Repository

This repository contains my hands-on projects and practical tasks completed during the TechBiz Academy CCNA Networking Internship

The purpose of this internship is to develop practical networking skills using Cisco Packet Tracer and understand the fundamentals of computer networking, routing, switching, and network security

Learning Objectives

Understand computer networking fundamentals

Configure Cisco routers and switches using IOS CLI

Perform IPv4 addressing, subnetting, and VLSM

Configure VLANs and trunking

Implement static and dynamic routing

Configure network services such as DHCP, DNS, and NAT

Understand IPv6, ACLs, and network security

Troubleshoot common network issues

Tools and Technologies

Cisco Packet Tracer

Cisco IOS CLI

IPv4 and IPv6

Routing and Switching

Network Security
